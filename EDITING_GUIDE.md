# TOFHI Website — Easy Edit Guide

## Quick edits
- **Hero image:** replace `images/image-1.*` (or the image referenced in the hero `<img>`) with your new image, then update the filename in `index.html` if needed.
- **Logo:** look for the `<img>` inside the navigation/header and change its `src`.
- **Text:** edit the visible text directly in `index.html`.
- **Phone:** search for `08084648748`.
- **Email:** search for `tofhinitiative@gmail.com`.
- **Social handle:** search for `tofhinitiative`.
- **Colors/layout:** edit `css/style.css`.

## Folder structure
```
tofhi-easy-edit/
├── index.html
├── images/
└── css/
    └── style.css
```

## Publishing on GitHub Pages
Upload/replace the contents of this folder in your `tofhi-website` repository. GitHub Pages will automatically publish the changes from the `main` branch.

## Tip
For future hero photos, use JPG or WebP and keep the file reasonably compressed (roughly 1–2 MB or less) for faster loading.
